# 🌤️ Weather App V2

> A premium, glassmorphism-styled weather dashboard built with React & Vite.

![Version](https://img.shields.io/badge/version-2.0.0-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

## ✨ Overview
**Weather App V2** represents a complete UI overhaul of the classic weather dashboard. Featuring a stunning **Glassmorphism** aesthetic, real-time dynamic visualizations, and deep integration with the **Open-Meteo API**, it provides comprehensive weather data in a beautiful, responsive interface.

## 🚀 New in v2.0
- **Glassmorphism Theme**: Frosted glass panels, dynamic gradients, and ambient lighting effects.
- **Dynamic Hourly Forecast**: Interactive bars showing daily temperature ranges relative to weekly extremes.
- **Sun Cycle Visualization**: Real-time SVG arc tracking sunrise and sunset.
- **Enhanced Typography**: Upgraded to **Inter** font for superior readability.
- **Optimized Performance**: Zero-dependency weather fetching.

## 🛠️ Tech Stack
- **Frontend**: React 18, Vite
- **Styling**: Vanilla CSS3 (Custom Glass Theme), CSS Variables, Grid/Flexbox
- **Icons**: Lucide React
- **Data Source**: [Open-Meteo API](https://open-meteo.com/) (Free, No Key Required)
- **Geocoding**: BigDataCloud API

## 📦 Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/weather-app-v2.git
   cd weather-app-v2
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   ```

## 🏗️ Building for Production
To create a production-ready build:
```bash
npm run build
```
